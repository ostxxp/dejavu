# Фаза 3 — разбор скопированного

## Что готово

Опциональный монитор NSPasteboard, локальное определение французского, подавление повторов, отдельное разрешение авторазбора до 500 символов, подтверждение длинного текста, одна всплывающая панель, озвучивание, сохранение, подробности, история и включение/выключение из строки меню. Версия 0.3.0.

Настройки и автоотправка выключены по умолчанию. Старое содержимое при включении не читается. Неподходящие данные отбрасываются до сетевого запроса; сырые копирования не записываются в историю или логи. После выключения текущий запрос отменяется, поздние результаты игнорируются. Ключ остаётся в Keychain.

## Как проверить

1. Запустите `build/Build/Products/Release/DejavuApp.app` или проект из Xcode.
2. В настройках включите «Разбор скопированного», оставив авторазбор выключенным. Скопируйте в другом приложении `Je voudrais apprendre le français avec toi tous les jours.`. Ожидается предложение «Разобрать» / «Игнорировать» без запроса к ИИ до нажатия.
3. Нажмите «Разобрать», проверьте реальный ответ, «Прослушать», «Сохранить», «Подробнее». Сохранённое выражение должно появиться в общем словаре, источник истории — «Скопированный текст».
4. Для автоматического режима включите отдельный переключатель и скопируйте другую французскую фразу до 500 символов. Текст из 501–4 000 символов всегда требует нажатия; более 4 000 пропускается.
5. Повторите копирование того же текста: новая отправка подавляется на 10 минут. Скопируйте английский текст, URL или файл: предложение не появляется.
6. Проверьте, что панель не забирает фокус. Наведение задерживает скрытие; вне панели ответ исчезает через 20 секунд, предложение — через 60. Новая фраза заменяет старую панель.
7. Отключите всплывающее окно: текущий результат доступен через «Последний разбор скопированного» в строке меню до истечения срока. Выключите разбор из того же меню: чтение и текущая обработка прекращаются.
8. Отключите общую историю либо историю скопированного и выполните разбор: автоматической записи нет, явное сохранение доступно.

Не используйте личные данные для проверки. Местный фильтр языка и типичных секретов не гарантирует распознавание всех чувствительных текстов. Короткие неоднозначные слова могут пропускаться.

## Результаты проверки

- 41 тест прошёл, 0 ошибок, 0 пропусков. Включены прежние проверки фаз 1–2.
- Новые проверки: границы длины и уверенности языка, русский/английский текст, URL/секретоподобные данные; повторные копирования; отсутствие чтения при выключении и на старте; debounce и смена буфера во время чтения; ручное подтверждение; отмена и поздний ответ; оба переключателя истории; отсутствие записи сырого запроса; сохранение настроек.
- Проверено чтение настоящего отдельного NSPasteboard, включая маркеры скрытого содержимого и файла. Общий пользовательский буфер тестами не читался и не изменялся.
- Нативная NSPanel проверена в тестовом процессе: сохранение текущего key window, отсутствие накопления окон, замена содержимого, пауза на наведении и истечение срока. Для теста срока использовалась сокращённая длительность.
- Миграция дисковой схемы настроек фазы 2 прошла: предыдущая модель и настройка истории сохранились, новые переключатели чтения и автоотправки выключены.
- Debug-тесты и чистая Release-сборка завершились успешно. Локальная подпись проверена `codesign --verify --deep --strict`.
- Release запущена через интерфейс; существующая пользовательская база открылась, версия 0.3.0 и новые выключенные переключатели подтверждены визуально. Отдельный живой путь «общий буфер → сеть» не запускался: пользовательский монитор не включался. Сеть и реальный провайдер остаются общими с проверенными предыдущими фазами.
- Проверено на Apple Silicon, macOS 26.0.1, Xcode 26.2. Отдельный Mac с macOS 14 и физические дополнительные дисплеи не проверялись. Xcode выдаёт диагностическое предупреждение DVTDeviceOperation, не мешающее сборке и тестам.

## Статус сборки

```sh
xcodebuild -quiet -project macos/DejavuApp.xcodeproj -scheme DejavuApp -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath /tmp/dejavu-derived test
xcodebuild -quiet -project macos/DejavuApp.xcodeproj -scheme DejavuApp -configuration Release -destination 'platform=macOS,arch=arm64' -derivedDataPath build clean build
codesign --verify --deep --strict build/Build/Products/Release/DejavuApp.app
```

Приложение собрано для локального запуска, без Developer ID/notarization. Сборки, базы и тестовые результаты не публикуются.
