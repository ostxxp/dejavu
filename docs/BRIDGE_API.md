# Локальный HTTP API — версия 1

Фаза 4. Адрес: `http://127.0.0.1:17389`. Сервер работает, пока приложение запущено и подключение включено в настройках. Только IPv4 loopback; `localhost`, IPv6 и LAN-адреса не являются альтернативными точками доступа. Расширение Chrome будет реализовано в фазе 5.

## Авторизация и Origin

Все операции требуют заголовок `Authorization: Bearer <local-pairing-code>`; здесь и ниже — только заглушки. Получить код можно в настройках приложения после включения моста. Не передавайте его в URL, не сохраняйте в репозитории или shell history. Ключ OpenAI никогда не является кодом подключения.

`Host` должен быть в точности `127.0.0.1:17389`. Если присутствует `Origin`, он должен быть равен `chrome-extension://<configured-extension-id>`. ID задаётся в настройках. Обычные HTTP(S)-страницы, `Origin: null`, другие расширения и пустой список разрешённых расширений получают отказ. Originless локальный клиент допускается только с авторизацией.

OPTIONS без кода разрешён только с точным разрешённым Origin, методом GET/POST и запрашиваемыми заголовками Authorization/Content-Type. Возвращает 204, точный Access-Control-Allow-Origin и соответствующие CORS-заголовки. Preflight не предоставляет доступ к данным. Для разрешённого расширения поддержан запрос Access-Control-Request-Private-Network. Browser-specific Local Network Access permissions/host permissions будут проверяться с реальным расширением в фазе 5.

## GET /v1/health

Успех, 200:

```json
{"status":"ok","version":"1","appVersion":"0.6.0"}
```

Не обращается к ИИ и не возвращает настройки, ключи, код подключения или историю.

## POST /v1/analyze

Content-Type: application/json. Тело:

```json
{"text":"tu devrais"}
```

`text` — непустое выражение или вопрос о французском, до 4 000 символов после удаления крайних пробелов. Только явный запрос клиента; сервер не читает страницы браузера.

Ответ 200 содержит `id` (UUID), `analysis` (объект из shared/schemas/french-analysis.json) и `fromCache` (boolean). Один и тот же запрос может использовать общий кэш приложения. Выданный ID действует до 30 минут, пока запись не вытеснена из последних 100 результатов, история не очищена и мост не перезапущен/отключён. Получите новый разбор, если ID устарел.

История записывается только при включённой общей истории. Сырые вопросы браузера и URL страниц не сохраняются.

## POST /v1/save

Content-Type: application/json. Тело:

```json
{"id":"00000000-0000-0000-0000-000000000000"}
```

UUID выше — заглушка; используйте ID собственного ответа /v1/analyze. Произвольный разбор в теле не принимается. Успех 200: `{"saved":true}`. Повторное сохранение идемпотентно; сохраняет выражение в общий словарь с источником «Выделенный текст». При выключенной истории явное сохранение доступно.

## Ошибки и ограничения

Формат: `{"error":{"code":"unauthorized","message":"Нужен действующий код подключения."}}`.

- 400: неверный HTTP, JSON или текст.
- 401: код отсутствует или не принят.
- 403: неправильный Host, Origin или preflight.
- 404: маршрут отсутствует либо ID разбора устарел/неизвестен.
- 405: метод не подходит маршруту анализа/сохранения.
- 413: превышен размер.
- 415: требуется application/json.
- 429: занято или превышен лимит (2 одновременных анализа, 20 в минуту), либо лимит провайдера.
- 500: ошибка локального сохранения/внутренняя ошибка.
- 502: ошибка или некорректный ответ провайдера.
- 503: мост выключен, запрос отменён, подключение ИИ не настроено либо результат инвалидирован.
- 504: таймаут провайдера.

HTTP/1.1, один запрос на соединение, `Connection: close`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`. Заголовки до 8 KiB, тело до 16 KiB (ограничение байтов действует дополнительно к длине текста), Content-Length обязателен для POST. Chunked encoding, Expect, дублирующиеся заголовки, query string и pipelining не поддерживаются. Максимум 16 соединений; чтение — до 10 секунд, вся операция — до 95 секунд. При превышении срока или разрыве клиента соединение закрывается, работа отменяется.

/v1/explain и /v1/listen не реализованы в этой фазе. Никакого доступа к Keychain или истории по HTTP нет.
