# Фаза 7 — полировка 0.7.0

## Что готово

Короткое знакомство с приложением: первый запуск, пропуск, переход к настройкам ИИ и повторный просмотр с главной. Дополнительные функции и разрешения не включаются. Существующая установка мигрирует без повторного онбординга.

Пустой словарь теперь предлагает начать разбор; пустая история объясняет, выключено ли её сохранение. Добавлены понятные состояния разрешений голоса, доступное имя кнопки закрытия мини-диалога, ссылки на настройки macOS и обычная кнопка «Начать мини-диалог» вместо обозначения пробного запуска. Нативные экраны используют семантические цвета; расширение поддерживает светлую/тёмную тему. Короткие переходы учитывают уменьшенное движение.

Смена ключа/модели и очистка кэша отменяют активные ИИ-запросы и очищают временные результаты; словарь не затрагивается. В расширении неожиданные ошибки Chrome превращаются в русское сообщение, а вложенные поля ответа проверяются перед отрисовкой.

## Исправленное падение голоса

Ручная проверка обнаружила аварийное завершение при ответе macOS на запрос разрешения Speech. Локальный отчёт показал Swift 6 isolation trap в callback SFSpeechRecognizerAuthorizationStatus: callback исполнялся на фоновой очереди, но наследовал MainActor. Мост разрешения теперь nonisolated, callbacks разрешения и аудиопотока явно Sendable; обновления интерфейса выполняются на MainActor. Тест воспроизводит ответ разрешения с фоновой DispatchQueue без доступа к настоящему микрофону.

При проверке реального ответа ИИ обнаружена русская вставка в поле французской полезной фразы. Инструкция уточнена; французские поля теперь отклоняют кириллицу. Ошибки перевода, которые структурно корректны, всё ещё возможны и требуют проверки пользователем.

## Результаты проверки

- 65 нативных тестов прошли без ошибок и пропусков, включая фоновой callback разрешения, завершение знакомства без включения интеграций, миграцию существующих настроек и отказ от смешанной французско-русской фразы.
- 13 тестов расширения прошли, включая некорректные вложенные поля и безопасные сообщения неожиданных ошибок.
- Чистая Release-сборка успешна. 0.7.0 запущена с существующими данными и сохранёнными пользовательскими настройками.
- Настоящий письменный мини-диалог и обратная связь проверены в UI; обнаруженная ошибка структуры фразы исправлена и покрыта тестом.
- Пользовательская проверка голоса выявила падение; после исправления пользователь повторно проверил голосовой ввод в 0.7.0 и подтвердил, что он работает.
- В живом интерфейсе просмотрены все три экрана знакомства; переходы «Далее» и «Открыть приложение» работают. Повторное открытие с главной и пустой словарь с действием «Разобрать выражение» проверены. Обновление существующей базы не открыло знакомство автоматически.
- Тёмная тема расширения, VoiceOver, уменьшенное движение, длительное расписание, несколько мониторов и обновление расширения остаются пунктами дополнительной ручной проверки; они не считаются пройденными на основании unit-тестов.

## Как проверить

1. Перезапустите `build/Build/Products/Release/DejavuApp.app`. На главной откройте «Как пользоваться DéjàVu», пройдите три экрана, проверьте «Назад», «Пропустить» и «Настроить ИИ». Ваши настройки дополнительных функций не должны измениться.
2. «Настройки → Мини-диалоги → Начать мини-диалог»: дождитесь вопроса, ответьте письменно, сохраните полезную фразу и найдите её в общем словаре. Убедитесь, что перевод отделён от французского текста.
3. В новом диалоге нажмите «Ответить голосом», разрешите доступ при запросе, произнесите французскую фразу, остановите запись и проверьте расшифровку. Закрытие окна должно остановить микрофон. Письменный ввод остаётся доступным при отказе в разрешениях.
4. В Chrome откройте `chrome://extensions`, нажмите Reload у DéjàVu, обновите учебную страницу. Проверьте разбор, сохранение, подробности и внешний вид в текущей теме. Ключ и локальный код заново вводить не нужно, если ID/папка прежние.
5. Проверьте клавиатурную навигацию, Escape, режим уменьшенного движения и пустые состояния словаря/истории на тестовой установке. Не очищайте рабочие данные ради проверки.

## Статус сборки

```sh
xcodebuild -quiet -project macos/DejavuApp.xcodeproj -scheme DejavuApp -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath /tmp/dejavu-derived test
node --test chrome-extension/tests/*.test.js
xcodebuild -quiet -project macos/DejavuApp.xcodeproj -scheme DejavuApp -configuration Release -destination 'platform=macOS,arch=arm64' -derivedDataPath build clean build
codesign --verify --deep --strict build/Build/Products/Release/DejavuApp.app
```

Среда: Apple Silicon, macOS 26.0.1, Xcode 26.2. Сборка локальная ad-hoc; Developer ID/notarization и Chrome Web Store не настроены. Гарантия распознавания всех помех, Focus или демонстраций экрана не заявляется: используются эвристики, описанные в фазе 6. Отчёты сбоя, записи, пользовательские данные, ключи и результаты тестов в Git не добавляются.
