# DéjàVu для Chrome

Версия 0.7.0. Manifest V3, Chrome 120+, JavaScript без внешних зависимостей. Разбор выполняет приложение DéjàVu на Mac. Ключ OpenAI остаётся в Keychain приложения.

## Установка и подключение

1. Соберите и запустите приложение по инструкции в корневом README.
2. В Chrome откройте `chrome://extensions`, включите Developer mode, нажмите Load unpacked и выберите **эту папку `chrome-extension`**, не корень репозитория.
3. Откройте DéjàVu через меню расширений Chrome. Скопируйте показанный ID расширения в «Настройки → Расширение Chrome» приложения.
4. В приложении включите подключение, покажите и скопируйте код. Вставьте его в поле «Код подключения» расширения и нажмите «Подключить». Не используйте здесь ключ OpenAI.
5. Обновите уже открытые веб-страницы. Выделите `tu devrais` и нажмите «Разобрать» рядом с выделением.

Кнопки результата: «Слушать», «Сохранить», «Подробнее». Для озвучивания нужен установленный локальный голос fr-FR. Меню расширения позволяет выключить подсказки, исключить домен вместе с поддоменами, проверить соединение и открыть приложение.

После обновления файлов нажмите Reload на карточке расширения и обновите тестируемую страницу. Перемещение папки может изменить ID; тогда потребуется заново указать его в приложении.

## Данные и разрешения

- Скрипт работает на обычных HTTP/HTTPS-страницах, только в главном фрейме. Поля ввода, пароли, редактируемые области и блоки кода исключены. Служебные страницы Chrome, PDF-просмотрщик и файлы не поддерживаются.
- Определение языка локальное. Само выделение не вызывает запрос к приложению или ИИ. Нажатие «Разобрать» отправляет только выделенный текст.
- `storage`: локальные настройки и отдельный код подключения, без синхронизации. Код доступен только доверенным контекстам расширения. Расширение не шифрует его отдельно от профиля Chrome; для отзыва замените код в приложении.
- `activeTab`: домен текущей вкладки для кнопки исключения сайта. `tts`: локальная французская озвучка.
- Сетевой адрес жёстко ограничен `http://127.0.0.1:17389`; перенаправления запрещены. Нет аналитики, удалённого кода и внешних ресурсов.
- В session storage остаются временные ID разбора и исходное выражение для озвучивания (до 100 записей, 30 минут). Полная учебная база хранится только в приложении.
- Фильтрация не определяет всю чувствительную информацию: проверяйте выделение перед нажатием «Разобрать».

## Проверки

Из корня проекта: `node --test chrome-extension/tests/*.test.js` (Node.js 20+).

Для ручной проверки можно запустить `python3 -m http.server 17400 --bind 127.0.0.1 --directory chrome-extension/tests/fixtures` и открыть `http://127.0.0.1:17400/article.html`. Доступны обычная статья, страница с агрессивным CSS и страница с исключаемыми полями. Сервер обслуживает только тестовые страницы, не файлы проекта.

Меню и карточка следуют светлой/тёмной теме системы. Появление карточки учитывает предпочтение уменьшенного движения. Неожиданные технические ошибки не показываются дословно; некорректные вложенные поля разбора отклоняются до отрисовки.
