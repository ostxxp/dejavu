# DéjàVu

Нативный помощник по французскому для macOS. Для русскоязычного ученика A2 → B1: понять выражение, сохранить полезное и встретить его снова.

Реализованы **фазы 1–4 — основа приложения, быстрый помощник, разбор скопированного и локальный мост**. Следующие фазы начинаются только по отдельному указанию.

## Уже доступно

- Окно с разделами «Главная», «Сохранённое», «История», «Настройки» и меню в строке macOS.
- Ручной разбор выражений и вопросов через OpenAI; русский перевод, транскрипция, грамматика, примеры.
- Единый словарь с дедупликацией, историей встреч, сохранением выражений и заметками.
- Поиск по сохранённому и истории, очистка истории с сохранением выбранных выражений.
- Настройка модели, ключ в Keychain, проверка подключения и отключение истории.

- Быстрый помощник в отдельной панели: ⌘⇧F, свободный вопрос, компактный ответ и подробности.
- Озвучивание французских выражений и примеров системным голосом fr-FR.
- Одно уточнение с контекстом предыдущего ответа, история последних 100 успешных вопросов.
- Общий кэш ответов в памяти: до 100 записей на 30 минут, с явным обновлением ответа.

- Разбор скопированного с локальным определением французского, отдельным включением авторазбора и всплывающей панелью.

- Локальный HTTP-мост с отдельным кодом подключения, авторизацией, разбором и сохранением.

Chrome и мини-диалоги относятся к следующим фазам.

## Быстрый помощник

При работающем приложении нажмите ⌘⇧F (физическая клавиша F). Панель также доступна из строки меню и «Главной». Если сочетание занято другим приложением, в настройках появится сообщение и кнопка повторной регистрации.

Введите выражение или вопрос, например `Чем отличаются leur и leurs?`, и нажмите Enter. ⌘S сохраняет выражение в общий словарь, ⌘L произносит его, «Подробнее» раскрывает разбор. «Задать уточнение» разрешает один дополнительный вопрос к ответу. Для следующей темы — ⌘K. ↑ и ↓ листают успешные вопросы и возвращают текущий черновик; Esc закрывает панель и отменяет текущий запрос.

Повторный идентичный запрос использует кэш с отметкой «без нового запроса». «Обновить ответ» обращается к ИИ заново. Кэш учитывает модель и контекст уточнения; очищается при выходе, смене ключа и вручную из настроек. Отключение истории запрещает запись новых вопросов и разборов, включая ответы на уже выполнявшиеся запросы. Очистка истории удаляет также вопросы, контекст и кэш, сохраняя выбранные выражения.

## Разбор скопированного

По умолчанию выключен, включая автоматическую отправку. В «Настройках» включите «Разбор скопированного», затем скопируйте французскую фразу в другом приложении. Содержимое, скопированное до включения, не читается. Обычный режим сначала предлагает «Разобрать» / «Игнорировать»; до нажатия текст остаётся локально.

«Автоматически разбирать французский текст» разрешает отправку вероятно французского текста до 500 символов в OpenAI. От 501 до 4 000 символов всегда требуется нажатие «Разобрать». Более длинные тексты пропускаются. Язык определяется локальным NaturalLanguage; короткие неоднозначные слова могут быть пропущены — их можно ввести в быстром помощнике.

Панель не забирает фокус при появлении, заменяет предыдущий результат и скрывается через 20 секунд; предложение разбора — через 60 секунд. Наведение мыши приостанавливает скрытие. Доступны сохранение, озвучивание, подробности и закрытие. Если всплывающие окна выключены, последний текст/ответ можно открыть из строки меню, пока он не истёк. Там же можно мгновенно выключить проверку буфера.

Повтор одного текста подавляется на 10 минут (до 50 отпечатков в памяти). Маркированные скрытые/временные данные, файлы, URL, адреса электронной почты, типичные токены и явно нефранцузский текст пропускаются. Эти проверки не гарантируют обнаружение всех личных данных: не копируйте их при включённом авторазборе. Новые копирования отменяют предыдущий запрос и убирают старую панель.

Сырые копирования не записываются в базу и логи. Только успешный разбор может попасть в историю, если включены и общая история, и история скопированного. Сохранение выражения — отдельное явное действие. Ключ остаётся в Keychain. Чтение буфера не требует Accessibility или микрофона; возможный системный запрос доступа к вставке не обходится.

## Подключение браузера

В настройках появился раздел «Расширение Chrome». Мост выключен по умолчанию. «Подключить расширение» запускает сервер только на `127.0.0.1:17389`. После запуска можно показать и скопировать отдельный код подключения. Он хранится в Keychain и даёт доступ к разбору через ИИ и сохранению выражений; ключ OpenAI через мост не передаётся.

Для запросов с браузерным Origin необходимо указать точный ID расширения (32 буквы a–p). Запросы с сайтов и других расширений отклоняются. Пустое поле допускает только запросы без Origin с действующим кодом — для локального клиента. Chrome-расширение ещё не реализовано и появится в фазе 5.

«Заменить код подключения» отзывает прежний код и закрывает текущие соединения. «Отключить» останавливает сервер. При занятом порте появится сообщение: закройте другую копию приложения и повторите подключение. Не публикуйте код и не вставляйте его на сайтах.

Контракт и ограничения: [локальный HTTP API](docs/BRIDGE_API.md).

## Запуск

Нужны macOS 14+ и Xcode 16+ с поддержкой Swift 6. Проверено на Xcode 26.2, Apple Silicon. Сборка не требует внешних пакетов, генератора проектов или платной учётной записи разработчика: используется локальная ad-hoc подпись.

1. Откройте `macos/DejavuApp.xcodeproj`.
2. Выберите схему `DejavuApp`, устройство «Мой Mac» и нажмите ⌘R.
3. Откройте «Настройки», введите свой ключ OpenAI и нажмите «Сохранить ключ».
4. При необходимости измените модель и нажмите «Сохранить настройки». По умолчанию — `gpt-4o-mini`.
5. Нажмите «Проверить подключение». Проверка использует сохранённые настройки и отправляет один небольшой платный запрос со словом `bonjour`.
6. На «Главной» введите `tu devrais` и нажмите «Разобрать».

Без ключа можно открыть приложение, проверить навигацию, пустые состояния и настройки. Реальные ответы требуют доступной модели и средств на аккаунте OpenAI.

Закрытие главного окна оставляет приложение в строке меню. Для полного завершения — «Выход» или ⌘Q. Настройки также открываются через ⌘,.

## Сборка и тесты

Из корня репозитория:

```sh
git config core.hooksPath .githooks
xcodebuild -project macos/DejavuApp.xcodeproj -scheme DejavuApp \
  -configuration Debug -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/dejavu-derived build

xcodebuild -project macos/DejavuApp.xcodeproj -scheme DejavuApp \
  -configuration Debug -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/dejavu-derived test
```

Для Intel замените `arm64` на `x86_64`. XCTest использует временные базы и фиктивные сетевые ответы, не требует ключа и не обращается в OpenAI. Тест Keychain создаёт и удаляет отдельную запись с фиктивным значением. Данные пользователя тестами не изменяются.

Собранное приложение: `/tmp/dejavu-derived/Build/Products/Debug/DejavuApp.app`. Эта сборка предназначена для локального запуска; распространение с Developer ID и notarization пока не настроено.

## Данные и ключи

SwiftData хранит словарь, успешные разборы и настройки в контейнере приложения, в `Library/Application Support`. Синхронизация iCloud отключена. Не переносите содержимое контейнера в репозиторий. Выключение истории прекращает автоматическое сохранение новых разборов; кнопка «Сохранить» остаётся явным действием пользователя.

Ключ находится только в локальной Keychain и временно в памяти при запросе. Он не сохраняется в SwiftData, UserDefaults, файлах проекта или логах. В тестах используются исключительно фиктивные значения. После изменения локальной подписи macOS может заново запросить доступ к записи Keychain.

Сервис обращается только к `https://api.openai.com/v1/responses`, использует `store: false`, строгую JSON-схему и сессию без дискового кэша. Перенаправления HTTP запрещены. Ответы и ошибки сервера не выводятся в лог или интерфейс напрямую. `store: false` не отменяет политику обработки данных поставщика.

`.gitignore` и `.githooks/pre-commit` защищают от типичных секретных файлов и форматов токенов. Для hook нужен Python 3; после клонирования его необходимо включить командой выше. Он не заменяет просмотр staged diff и всех публикуемых коммитов. Каждая законченная фича — отдельный коммит; проверенные коммиты пушатся в GitHub.
