# DéjàVu

Нативный помощник по французскому для macOS. Для русскоязычного ученика A2 → B1: понять выражение, сохранить полезное и встретить его снова.

Реализована **фаза 1 — основа приложения**. Следующие фазы начинаются только по отдельному указанию.

## Уже доступно

- Окно с разделами «Главная», «Сохранённое», «История», «Настройки» и меню в строке macOS.
- Ручной разбор выражений и вопросов через OpenAI; русский перевод, транскрипция, грамматика, примеры.
- Единый словарь с дедупликацией, историей встреч, сохранением выражений и заметками.
- Поиск по сохранённому и истории, очистка истории с сохранением выбранных выражений.
- Настройка модели, ключ в Keychain, проверка подключения и отключение истории.

Горячая клавиша, всплывающий помощник, буфер обмена, озвучивание, мост, Chrome и мини-диалоги относятся к следующим фазам и пока не реализованы.

## Запуск

Нужны macOS 14+ и Xcode 16+ с поддержкой Swift 6. Проверено на Xcode 26.2, Apple Silicon. Сборка не требует внешних пакетов, генератора проектов или платной учётной записи разработчика: используется локальная ad-hoc подпись.

1. Откройте `macos/DejavuApp.xcodeproj`.
2. Выберите схему `DejavuApp`, устройство «Мой Mac» и нажмите ⌘R.
3. Откройте «Настройки», введите свой ключ OpenAI и нажмите «Сохранить ключ».
4. При необходимости измените модель и нажмите «Сохранить настройки». По умолчанию — `gpt-4o-mini`.
5. Нажмите «Проверить подключение». Проверка использует сохранённые настройки и отправляет один небольшой платный запрос со словом `bonjour`.
6. На «Главной» введите `tu devrais` и нажмите «Разобрать».

Без ключа можно открыть приложение, проверить навигацию, пустые состояния и настройки. Реальные ответы требуют доступной модели и средств на аккаунте OpenAI.

Закрытие главного окна оставляет приложение в строке меню. Для полного завершения — «Выход» или ⌘Q. Настройки также открываются через ⌘,.

## Сборка и тесты

Из корня репозитория:

```sh
git config core.hooksPath .githooks
xcodebuild -project macos/DejavuApp.xcodeproj -scheme DejavuApp \
  -configuration Debug -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/dejavu-derived build

xcodebuild -project macos/DejavuApp.xcodeproj -scheme DejavuApp \
  -configuration Debug -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/dejavu-derived test
```

Для Intel замените `arm64` на `x86_64`. XCTest использует временные базы и фиктивные сетевые ответы, не требует ключа и не обращается в OpenAI. Тест Keychain создаёт и удаляет отдельную запись с фиктивным значением. Данные пользователя тестами не изменяются.

Собранное приложение: `/tmp/dejavu-derived/Build/Products/Debug/DejavuApp.app`. Эта сборка предназначена для локального запуска; распространение с Developer ID и notarization пока не настроено.

## Данные и ключи

SwiftData хранит словарь, успешные разборы и настройки в контейнере приложения, в `Library/Application Support`. Синхронизация iCloud отключена. Не переносите содержимое контейнера в репозиторий. Выключение истории прекращает автоматическое сохранение новых разборов; кнопка «Сохранить» остаётся явным действием пользователя.

Ключ находится только в локальной Keychain и временно в памяти при запросе. Он не сохраняется в SwiftData, UserDefaults, файлах проекта или логах. В тестах используются исключительно фиктивные значения. После изменения локальной подписи macOS может заново запросить доступ к записи Keychain.

Сервис обращается только к `https://api.openai.com/v1/responses`, использует `store: false`, строгую JSON-схему и сессию без дискового кэша. Перенаправления HTTP запрещены. Ответы и ошибки сервера не выводятся в лог или интерфейс напрямую. `store: false` не отменяет политику обработки данных поставщика.

`.gitignore` и `.githooks/pre-commit` защищают от типичных секретных файлов и форматов токенов. Для hook нужен Python 3; после клонирования его необходимо включить командой выше. Он не заменяет просмотр staged diff и всех публикуемых коммитов. Каждая законченная фича — отдельный коммит; проверенные коммиты пушатся в GitHub.
