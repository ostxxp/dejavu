# DéjàVu

Приложение для изучения французского языка.

Проект находится на этапе подготовки. Функциональность и стек будут определены отдельно.

## Работа над проектом

- Каждая законченная фича — отдельный коммит.
- После завершения работы и проверки изменений — push в GitHub.
- Секреты, токены, пароли и приватные ключи не хранятся в репозитории, включая историю Git.

## Локальная защита

После клонирования включите проверку перед коммитом:

```sh
git config core.hooksPath .githooks
```

Проверка требует Python 3 и блокирует секретные файлы и некоторые известные форматы ключей в staged-изменениях. Она не заменяет просмотр diff перед публикацией. Локальные настройки храните в игнорируемом `.env`; примеры конфигурации должны содержать только фиктивные значения.
