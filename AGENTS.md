# DéjàVu

Приложение для изучения французского языка. Не выбирайте стек и не реализуйте фичи до соответствующего задания пользователя.

## Git workflow

- Каждую законченную фичу оформляйте отдельным содержательным коммитом.
- После завершения запрошенной работы и необходимых проверок пушьте все подготовленные коммиты.
- Перед коммитом проверяйте staged diff; перед push — все публикуемые коммиты.
- Не добавляйте секреты, API-ключи, токены, пароли, приватные ключи, реальные пользовательские данные или локальные credentials ни в файлы, ни в сообщения коммитов.
- Секреты храните вне Git, например в локальном игнорируемом `.env`. В примерах используйте только очевидные заглушки.
- Не обходите проверки секретов. После клонирования выполните `git config core.hooksPath .githooks`.
- Если секрет обнаружен в истории, остановите публикацию и устраните его из всех публикуемых коммитов; сообщите пользователю о необходимости отзыва/ротации раскрытого секрета.
